# 100-days-code-of-C

## Day 01
P1: Write a program to input two numbers and display their sum.
P2: Write a program to input two numbers and display their sum, difference, product, and quotient.

## Day 02
P1: Write a program to calculate the area and perimeter of a rectangle given its length and breadth.
P2: Write a program to calculate the area and circumference of a circle given its radius.

## Day 03
P1:Write a program to convert temperature from Celsius to Fahrenheit.
P2:Write a program to swap two numbers using a third variable.

## Day 04
P1:Write a program to swap two numbers without using a third variable.
P2:Write a program to find and display the sum of the first n natural numbers

## Day 05
P1:Write a program to calculate simple and compound interest for given principal, rate, and time.
P2:Write a program to input time in seconds and convert it to hours:minutes:seconds format.
