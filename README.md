# 100-days-code-of-C

## Day 01
P1: Write a program to input two numbers and display their sum.
P2: Write a program to input two numbers and display their sum, difference, product, and quotient.

## Day 02
P1: Write a program to calculate the area and perimeter of a rectangle given its length and breadth.
P2: Write a program to calculate the area and circumference of a circle given its radius.

## Day 03
P1:Write a program to convert temperature from Celsius to Fahrenheit.
P2:Write a program to swap two numbers using a third variable.

## Day 04
P1:Write a program to swap two numbers without using a third variable.
P2:Write a program to find and display the sum of the first n natural numbers

## Day 05
P1:Write a program to calculate simple and compound interest for given principal, rate, and time.
P2:Write a program to input time in seconds and convert it to hours:minutes:seconds format.

## Day 06
P1:Write a program to input an integer and check whether it is even or odd using if–else.
P2:Write a program to input an integer and check whether it is positive, negative or zero using nested if–else.

## Day 07
P1:Write a program to input a year and check whether it is a leap year or not using conditional statements.
P2:Write a program to input a character and check whether it is a vowel or consonant using if–else.

## Day 08
P1:Write a program to input a character and check whether it is an uppercase alphabet, lowercase alphabet, digit, or special character.
P2:Write a program to input three numbers and find the largest among them using if–else.

## Day 09
P1: Write a program to find the roots of a quadratic equation and categorize them.
P2: Write a program that accepts a percentage (0-100) and assigns a grade based on the following criteria: 
90-100: Grade A 
80-89: Grade B 
70-79: Grade C 
60-69: Grade D 
below 60: Grade F.

## Day 10
P1: Write a program to classify a triangle as Equilateral, Isosceles, or Scalene based on its side lengths.
P2: Write a program to display the day of the week based on a number (1–7) using switch-case.

## Day 11
P1: Write a program to display the month name and number of days using switch-case for a given month number.
P2: Write a program to find profit or loss percentage given cost price and selling price.

## Day 12
P1: Write a program to calculate library fine based on late days as follows: 
First 5 days late: ₹2/day 
Next 5 days late: ₹4/day 
Next 20 days days late: ₹6/day 
More than 30 days: Membership Cancelled.
P2: Write a program to calculate electricity bill based on units consumed with these rates: 
First 100 units at ₹5/unit 
Next 100 units at ₹7/unit 
Next 100 units at ₹10/unit 
Above at ₹12/unit
